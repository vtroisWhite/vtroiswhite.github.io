## 什么是 AI 工程师？

AI 工程师基于现有模型构建产品，比如聊天助手、文档搜索工具和能执行操作的 AI 智能体。他们通常通过 API 接入已经训练好的大语言模型（LLM），把模型的能力用到具体的业务场景中。

假设一家公司要做一个客服助手。模型能理解用户的问题，却无法直接查询这家公司的商品资料、退款政策和订单记录。工程师要为助手接入业务数据，明确哪些问题可以回答、哪些操作可以执行，测试回答质量，再把服务部署给客户使用。

在原文讨论的应用开发岗位中，招聘信息里的「生成式 AI 工程师」通常指类似的职责。「生成式」强调产品用到了能生成文本、图片或音频的模型，具体工作仍要看岗位描述。

## AI 工程师负责什么？

| 工作 | 要解决的问题 |
| --- | --- |
| 接入模型 | 通过 API 调用模型，设计提示词，处理响应、超时和限流。简单任务可以选速度快的小模型，复杂任务再按效果选择能力更强的模型。 |
| 检索增强生成（RAG） | 把文档分块，并为每个片段生成嵌入向量，方便按语义检索。工程师要决定怎么分块、存储和检索，以及给模型多少材料。例如，客服助手会在回答前检索对应的退款条款。 |
| AI 智能体 | 设计查询订单、发送邮件或创建工单等工具。模型提出工具调用请求和参数，由应用代码执行。工程师负责工具、执行循环、记忆，以及每个操作的权限和条件。 |
| 评估 | 从真实问题整理评估集和预期答案，测量系统输出。上线前用这套评估集检查提示词、模型或检索步骤的改动。 |
| 部署和运行 | 把系统部署成服务，处理并发，跟踪成本与请求日志，监控故障。 |

想了解这些环节涉及的基本概念，可以参考原作者的视频，涵盖大语言模型、RAG、模型上下文协议（MCP）、智能体、微调和量化。[AI 工程基础视频](https://www.youtube.com/watch?v=lnfWvX66FUk)

## 如何使用编程智能体开发？

AI 工程师可以用 Claude Code 或 Codex 等编程智能体实现一项明确的需求。工程师定义任务，审查生成的代码，验证行为，再根据结果调整设计。

以客服助手为例，需要写一个连接器，把帮助中心的文章同步到搜索索引。可以这样描述任务。

```text
编写一个连接器，通过帮助中心 API 读取全部帮助文章。
将每篇文章切成约 500 个词元的片段，为每个片段生成嵌入向量。
把片段和向量写入搜索索引。
为 API 调用失败添加重试，并记录每篇被跳过的文章。
```

拿到代码后，先看分块大小是否适合这些文档，再用十篇文章试跑，确认片段写入正确。接着用几个问题验证能否找回对应片段，并模拟帮助中心 API 不可用，观察连接器如何处理故障。能清楚地交代任务、发现实现问题并验证结果，是使用编程智能体的关键能力。

## AI 工程师的一天

继续以客服助手为例。下面是一组工作场景，评估分数用于说明排查和发布流程。

- **上午检查评估。** 团队昨晚换了模型，退款类问题的评估分数从 92% 降到了 85%。工程师查看失败样本，发现新模型经常回答得更长，有时漏掉可申请退款的具体天数。于是调整提示词，要求先给出退款期限，再让编程智能体更新模板和测试。重新评估后，分数回到 93%。
- **中午接入退货工具。** 产品经理希望助手能创建退货申请。工程师先确定工具的输入、输出和约束，例如必须确认订单号才能创建申请。随后审查编程智能体生成的实现和测试，用模拟订单服务验证，并补充五条退货申请的评估用例。
- **下午排查成本。** 月度 API 费用上升。工程师从请求日志发现，有些调用带上了完整对话，其中包含已经用不到的旧消息。团队改为保留最近几轮和一段摘要，确认评估分数稳定后发布。
- **下班前交接。** 记录当天的变更、评估分数和后续需要关注的情况，再审查同事为 RAG 流程接入新文档来源的拉取请求。

## AI 工程师和机器学习工程师有什么区别？

机器学习工程师的工作通常更靠近模型，涉及训练数据、模型选择、训练、调优和推理服务。AI 工程师的工作通常更靠近产品，涉及模型 API、检索、智能体、评估和应用部署。

两者会在同一个项目里配合。例如，机器学习工程师用公司数据微调模型，AI 工程师把模型接入产品，再检查它能否改善真实任务的表现。前者一般需要更扎实的数学和训练基础设施知识，后者更看重软件工程、使用编程智能体的能力，以及对产品需求和输出质量的判断。

## 哪些人适合做 AI 工程师？

- **想为产品加入 AI 能力的后端或全栈工程师。** API、数据处理、测试和部署的经验都能用上。
- **更关心产品能否帮到用户的人。** 这类岗位每天都要把模型能力变成用户可用的功能。
- **愿意面对输出不确定性的人。** 相同输入可能得到不同回答，需要靠评估、测试和迭代持续改进。
- **能指挥并验证编程智能体的人。** 把任务描述清楚，审查生成的代码，并能识别其中的问题。

## 常见问题

### 生成式 AI 工程师是另一个岗位吗？

在面向生成式 AI 产品的团队里，这两个名称经常指相近的工作。看招聘信息时，可以重点确认岗位负责产品开发、模型训练还是两者都有。

### AI 工程师需要训练模型吗？

应用开发通常从已有模型开始。需要用公司数据进一步训练时，团队可以由机器学习工程师负责微调，再由 AI 工程师完成集成和效果评估。

### 需要研究经历或很深的数学基础吗？

对这类应用开发岗位，重点是理解模型会怎样回答、在哪些情况下容易失败，以及怎样通过系统设计处理这些问题。训练模型所需的研究和数学背景通常属于另一类岗位要求。

### 为什么每次改动都要评估？

模型对同一个问题的输出可能变化，调整提示词也可能同时影响许多回答。在真实问题组成的评估集上复跑，可以判断改动是否提升了质量，以及原本有效的回答有没有退步。
